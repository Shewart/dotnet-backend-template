Hey developers! 👋 Welcome to our **dotnet-backend-template** community discussions!

## 🎯 **What is this template?**

This is a **production-ready .NET backend template** featuring:
- 🏗️ **Clean Architecture** - Properly structured layers  
- 🗃️ **MongoDB Integration** - Generic CRUD operations out of the box
- ⚡ **Minimal APIs** - Fast, lightweight endpoints
- 🔧 **Easy Extension** - Add new entities in minutes
- 📦 **Template Ready** - `dotnet new` installable package

## 🔥 **Quick Start Reminder:**

```bash
# Clone the template
git clone https://github.com/yourusername/dotnet-backend-template
cd dotnet-backend-template

# Run the API
dotnet run --project Dotnet.Api

# Test endpoints
curl http://localhost:5087/api/products
```
